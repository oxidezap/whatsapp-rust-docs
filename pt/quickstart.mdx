Este exemplo usa a API do snapshot Git indicado abaixo. A versão publicada `0.7` tem uma API anterior; use a mesma revisão nos exemplos desta documentação. Veja o [guia de migração](/guides/migrating-current-api).

## Dependências

Uma dependência da lib basta: `whatsapp-rust` reexporta o backend SQLite, o transporte, o cliente HTTP e os tipos usados pelo bot.

```toml Cargo.toml
[dependencies]
whatsapp-rust = { git = "https://github.com/oxidezap/whatsapp-rust", rev = "ff7acaddf80169013b0fd06df65296db7e4a8ca3" }
tokio = { version = "1", features = ["macros", "rt-multi-thread"] }
```

## Bot mínimo

Salve este código em `src/main.rs`, execute `cargo run` e leia o QR code com o WhatsApp.

```rust src/main.rs
use whatsapp_rust::prelude::*;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let bot = Bot::builder()
        .with_backend(SqliteStore::open("whatsapp.db").await?)
        .on_qr_code(|code, _timeout| async move {
            println!("Leia este QR code com o WhatsApp:\n{code}");
        })
        .on_message(|ctx| async move {
            if ctx.message.text_content() == Some("ping") {
                if let Err(e) = ctx.reply("pong").await {
                    eprintln!("Falha ao responder: {e}");
                }
            }
        })
        .build()
        .await?;

    // Executa até logout ou client.disconnect() em outra tarefa.
    bot.run().await;
    Ok(())
}
```

`SqliteStore::open` mantém as chaves e a sessão em `whatsapp.db`. Ao reiniciar, reutilize o arquivo para recuperar a sessão.

`on_message` entrega um `MessageContext`: `ctx.reply` responde no chat de origem, `ctx.reply_quoting` inclui a mensagem original e `ctx.react` envia uma reação. Para enviar conteúdo protobuf, use `ctx.send_message`.
